Leaderboard Project

About the Project

This project is a simple leaderboard created using HTML, CSS, and JavaScript. It displays a list of players along with their scores, allowing users to easily view and compare rankings.

The main features of this leaderboard project include:

Responsive Design: The project is designed to be fully responsive, ensuring a seamless experience across different devices and screen sizes.

Add Players: Users can add new players by entering their names, countries, and scores.

Delete Players: Users can delete existing players from the leaderboard.

Automatic Sorting: The leaderboard automatically adjusts the order of players based on their scores, placing players with higher scores above those with lower scores.

This project is an excellent example of how HTML, CSS, and JavaScript can be used together to create an interactive and dynamic web application
